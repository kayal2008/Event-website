# Event Website

A simple event-themed static website built using HTML. The website presents upcoming event information, a photo gallery, event details, a fashion shop link, and contact information.

## 🌟 Features

- 📅 Upcoming Events section
- 🖼️ Photo Gallery Event
- 🛍️ Fashion Shop link
- 🎟️ Event information such as entry and food details
- 📞 Contact information
- 📍 Location details
- 🖼️ Image-based event presentation

## 🛠️ Tech Stack

- **HTML5**
- **Local Image Assets**

## 🎯 Project Purpose

This project was created to practice building a basic static webpage using HTML elements such as headings, images, links, horizontal lines, and text sections.

It demonstrates how event-related information can be organized into a simple webpage.
